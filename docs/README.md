# Documentação do aplicativo

## Construção da interface

Antes de criar ou alterar telas, ler o [Design system Kobra do Pulse](design-system.md) e o contrato de [Sons da interface](interface-sounds.md). Eles documentam o padrão atual incorporado em `develop`: temas claro/escuro, tokens, componentes, marca, movimento, feedback e áudio. Usar os componentes locais e a composição da aplicação atual como referência para novas funcionalidades.

| Documento | Uso |
|---|---|
| [Design system](design-system.md) | Paleta, tema, tipografia, componentes, formulários e padrões para futuras telas |
| [Sons da interface](interface-sounds.md) | Disparos automáticos, preferências, eventos, toasts e exemplos |
| [Interface](ui.md) | Dashboard, apresentação, navegação, escalas, modais e estados de leitura |
| [Encaixe da raiz](overview-fit.md) | Altura, grade e rolagem interna dos blocos do dashboard |
| [Minicards](availability-cards.md) | Composição, dimensões e estados da Disponibilidade de Serviços |
| [Administração](administration.md) | Configuração, edição, revisão e prévias |
| [Infraestrutura](infrastructure.md) | Navegação e dados de host, VM e histórico |
| [Templates](templates.md) | Identidade, capacidades e preferências de templates |
